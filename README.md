# Type Grow

Écris un mot, il pousse. Une variation sur [Type Garden](https://type-garden.vercel.app) d'Akshat Agarwal : chaque mot reconnu fait pousser son propre motif (une centaine de fleurs et d'arbres dessinés à la main, des animaux qui se baladent sous les lettres, des références pop culture, des icônes pour les objets), en français, anglais, japonais, chinois et arabe.

- `index.html` : Type Grow
- `classique.html` : la version fidèle à Type Garden
- `verger.html` : la variante arbres fruitiers

`?t=texte` dans l'adresse fait pousser un texte tout seul.
